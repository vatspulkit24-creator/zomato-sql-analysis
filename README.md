# Zomato Restaurant Business Analysis

SQL and Power BI analysis of the Zomato restaurant dataset.

## Dashboard Preview
![Zomato Dashboard](dashboard.png)

## Tools Used
- MySQL
- Power BI
- Excel/CSV

## What I Analysed
- Total restaurants and city-wise distribution
- Top rated and most voted restaurants
- Rating distribution and city-wise average rating
- Price range and average cost for two
- Popular cuisines
- Online delivery and table booking availability
- Cost vs rating relationship

## Files
| File | Description |
|------|-------------|
| `zomato_restaurant_dataset.csv` | Raw dataset |
| `zomato_sql_analysis.sql` | All SQL queries |
| `zomato.pbix` | Power BI dashboard |
| `zomato_sql_business_analysis.docx` | Business analysis report |
